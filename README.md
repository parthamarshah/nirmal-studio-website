# Nirmal Studio

Public website for Nirmal Studio (Tej Shah). See `CLAUDE.md` for full project context
and decisions, and `progress.md` for build status.

## Run locally

```
npm install
npm run dev
```

Opens at `http://localhost:5173` by default.

## Build

```
npm run build
```

Output goes to `dist/`, which is what Cloudflare Pages deploys.
